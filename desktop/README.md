# 寻源 Windows 0.1.1 · 单文件便携版

适用于 Windows 10/11 x64。只需下载一个 `Xunyuan-Windows-0.1.1.exe`，双击运行，无需安装或另行安装 Java。不再提供安装程序。

## 搜索和筛选

- 默认复用安卓的六个已启用来源，支持网盘和磁力，来源可手动勾选。
- 结果按「全部资源、网盘、磁力、百度、夸克、迅雷、115、阿里、其他网盘」筛选，改变筛选立即作用于当前已收集结果。
- 每屏最多15条；结果显示完后可继续请求网站下一批，关键词不变。
- 网盘卡片显示提取码；未取得时标注「来源未提供」，不把缺少提取码当作无需提取码。
- 「只看有提取码的网盘」隐藏没有提取码的条目；来源提供的正文或链接参数里有提取码才会收录。
- 复制时同时复制链接和已知提取码；打开前把已知提取码复制到剪贴板。可「查看来源」查找缺失信息。
- 迅雷、115 支持链接识别及结果筛选，不保证搜索来源收录了这两类资源。无收录或网络不可达时不会伪造结果。
- 其他网盘包括当前解析器已识别的 UC、天翼、123 等。关键词过滤不能保证识别所有未标注内容。

扩展搜索每次启动默认关闭，开启前确认已满18岁；扩展来源须在来源列表另行勾选。请求由电脑直连来源站点，无自建搜索服务器。每个来源的错误可在「关于」查看。

## 便携运行

单个 EXE 内含运行环境，首次启动需要短暂解压。每次运行释放到独立的系统临时目录，正常退出后尝试清理；系统占用文件或异常断电时可能残留临时目录。无需管理员权限，不创建安装记录或桌面快捷方式。

收藏保存在 `%LOCALAPPDATA%\Xunyuan\favorites.json`，不自动上传；可携带 EXE 到另一台电脑，但收藏不会跟随 EXE 自动迁移。运行时设置仅保存在当前会话。

HTTPS 网盘分享链接交给系统浏览器或已注册关联的程序打开，不能保证直接启动网盘客户端。磁链需要已注册 magnet 协议的下载工具；打开失败会复制地址。

EXE 未做 Windows 代码签名，系统可能提示未知发布者。更新入口打开 Windows 发布列表供手动下载，不自动安装。

## 构建和验证

需要 JDK 21、Python 3。依赖 JAR 随仓库提供并校验 SHA256。Windows 单文件打包使用系统 .NET Framework C# 编译器，无需 WiX。

```sh
python desktop/build.py
# Windows 生成单文件 EXE：
python desktop/build.py --package
```

构建检查真实页面样本解析、分类与提取码关联、缺码标注、筛选和成人过滤；Windows 上还运行最终单文件 EXE，验证临时解压、内置运行环境启动、15条分页与交互筛选。来源实时可用性和用户电脑上的应用关联仍取决于当地网络及安装的软件。
