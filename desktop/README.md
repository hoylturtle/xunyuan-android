# 寻源 Windows 0.4.0 · 单文件便携版

适用于 Windows 10/11 x64。下载 `Xunyuan-Windows-0.4.0.zip`，解压得到固定名称 `Xunyuan.exe`，双击运行，无需安装或另行安装 Java。不再提供安装程序。

后续 Windows 版本默认使用带版本号的 ZIP 分发，包内程序固定名为 `Xunyuan.exe`。更新时先关闭旧版，再用新文件替换；程序版本仍显示在窗口、关于页及文件属性中。ZIP 不会替代代码签名，解压运行时仍可能出现 SmartScreen 提示。

## 图标与体积

0.4.0 修复透明处理造成图标内部颜色缺失的问题，绿色底和指南针保持不透明，只有圆角外侧透明；保留多尺寸翡翠绿指南针图标，覆盖EXE文件、窗口及任务栏。根据依赖分析移除未使用的运行模块，使用固实LZMA2压缩；仍为单文件便携版，不要求用户安装Java或7-Zip。运行时可能比旧版多用一些临时磁盘空间，压缩只改变分发体积，不改变搜索来源与结果。

## 鼠标操作与详情磁链

搜索结果和收藏列表支持右键菜单复制链接，Ctrl+C同样可复制。双击鼠标左键或按Enter打开应用内详情，显示标题、大小、日期、主磁链及网站可提供的文件列表；“打开资源”按钮仍交给系统关联的下载工具或浏览器。

3MAG / xcili 等结果只有网页地址时，复制操作会在后台读取详情页的 input#input-magnet（也兼容主磁链输入框或磁链锚点），复制完整磁链及其参数。成功后本次结果与收藏会改为磁链并按哈希合并，保留原网页、收藏分组和备注。详情只显示主文件表，不抓取相关推荐；读取失败明确提示，可打开原网页，不把网页地址当作磁链复制。不执行网页脚本、不加载广告，也不自动下载资源。

ZIP内固定为 Xunyuan.exe，ZIP文件名保留版本号。Windows代码签名状态不因本次功能更新而改变。

## 官方来源在线更新

0.4.0 默认启用9个云端实测可解析的普通来源；新增 Bitsearch、爱盼影视与 PanSou 公共聚合，其余旧问题来源保留为默认停用的备用项。云端通过不代表每个地区或每个关键词都可用，部分站点限制关键词或要求浏览器验证。旧的三个磁力站仅支持HTTP，已在来源说明标出。

“搜索来源”页可检查更新、开关每天自动检查以及回退上次在线来源。更新仅下载本项目 GitHub 的声明式JSON配置，沿用内置解析器，不下载或运行脚本。主地址失败时尝试同一项目的发布附件；网络失败、无效配置、不支持的格式、降级版本均保留当前可用配置。自动更新遇到在途搜索时先保存，下一次启动使用，避免中断搜索。

来源开关按ID保留；新目录中被标记默认停用的问题来源会停用一次，可再次手动勾选。回退会暂停自动更新，不允许低于本应用内置配置；收藏不变。配置、上次配置分别保存为 catalog.json、catalog.previous.json。新站需要新解析器或网页结构明显改动时，仍可能需要应用升级。

每日CI健康报告仅记录可用性，不会根据一次失败自动改写官方清单。来源维护步骤和证据见 [sources/README.md](../sources/README.md)。

## 新增分类、筛选和收藏管理

- 内容分类：不限制、电影、电视剧、电子书、软件。结合标题、季集标记和文件扩展名识别；分类不是网站给出的权威标签，未识别内容在“不限制”中保留。动漫电影、动画剧集按标题线索归类，无法确定时不强行分类。
- 内容分类与网盘／磁力筛选独立叠加；结果内包含词要求全部匹配，排除词任一匹配即隐藏，支持空格或逗号分隔。重置筛选可恢复已收集结果，不重新请求来源。
- 排序支持默认、相关度、有提取码、最新日期。缺失或无效日期排在已知日期之后，相同条件保持原顺序；不是根据电影上映日期排序。
- 收藏支持标题／分组／备注检索、分组备注编辑、Ctrl/Shift多选移除、JSON导入导出（可与安卓互用）、寻找替代地址。
- 复检选中网盘收藏；未选择时检查当前筛选可见的全部网盘收藏。串行检查，可停止；失效记录保留，磁力不作网盘有效性检查。
- 最近20次搜索、普通来源勾选状态保存至本机 settings.json；支持清除历史。扩展来源仍每次启动默认关闭。

## 搜索和筛选

- 默认启用9个实测普通来源，支持网盘和磁力，来源可手动勾选。
- 结果按「全部资源、网盘、磁力、百度、夸克、迅雷、115、阿里、其他网盘」筛选，改变筛选立即作用于当前已收集结果。
- 每屏最多15条；结果显示完后可继续请求网站下一批，关键词不变。
- 网盘卡片显示提取码；未取得时标注「来源未提供」，不把缺少提取码当作无需提取码。
- 「只看有提取码的网盘」隐藏没有提取码的条目；来源提供的正文或链接参数里有提取码才会收录。
- 复制时同时复制链接和已知提取码；打开前把已知提取码复制到剪贴板。可「查看来源」查找缺失信息。
- 迅雷、115 支持链接识别及结果筛选，不保证搜索来源收录了这两类资源。无收录或网络不可达时不会伪造结果。
- 其他网盘包括当前解析器已识别的 UC、天翼、123 等。关键词过滤不能保证识别所有未标注内容。

主界面不显示扩展搜索开关。连续点击左上角「寻源」名称6次（相邻两次不超过1.5秒），确认已满18岁后启用；再连点6次关闭，无需再确认。开启后名称旁增加一个小圆点；每次启动都恢复普通模式。

关闭会取消在途搜索，清空关键词、搜索结果和来源日志，隐藏识别出的成人收藏及扩展来源，并取消扩展来源勾选。开启时显示并勾选扩展来源。此入口只是界面隐藏方式，不是访问控制或家长控制。请求由电脑直连来源站点，无自建搜索服务器。每个来源的错误可在「关于」查看。

## 网盘有效性检查

搜索结果先经过独立的网盘检查队列，明确提示分享取消、删除、过期或返回404/410的条目不再显示。验证码、登录、403、429、服务错误、网络超时及只有脚本的动态页面标注「暂未确认」，不等同于失效。结果陆续显示，不必等全部慢来源完成。

检查只读取分享页面，不会登录账号、提交提取码、验证真实下载或自动保存文件。因此不能保证识别所有动态失效页，也不代表提取码正确。失效等明确结果缓存5分钟，未确认或连接失败缓存1分钟，最多512项；重复地址合并检查。关于页记录已隐藏的失效条目。

历史问题来源默认停用；手动勾选后仍可能增加等待时间；已知有结果的来源优先发起，请求仍有并发和超时限制。可以在来源页关闭不需要的来源。单页来源不反复翻页。

## 便携运行

单个 EXE 内含运行环境和精简解压程序，使用高压缩率的7z固实包；启动需要短暂解压。每次运行释放到独立的系统临时目录，正常退出后尝试清理；系统占用文件或异常断电时可能残留临时目录。无需管理员权限，不创建安装记录或桌面快捷方式。

收藏保存在 `%LOCALAPPDATA%\Xunyuan\favorites.json`，不自动上传；可携带 EXE 到另一台电脑，但收藏不会跟随 EXE 自动迁移。运行时设置仅保存在当前会话。

HTTPS 网盘分享链接交给系统浏览器或已注册关联的程序打开，不能保证直接启动网盘客户端。磁链需要已注册 magnet 协议的下载工具；打开失败会复制地址。

EXE 尚未使用受信任的 Windows 代码签名证书。Edge / Microsoft Defender SmartScreen 可能提示“通常不会下载”“发布者未知”，并默认显示删除；此为系统的下载信誉提示，不能仅凭此提示判定文件有无恶意内容。程序无法改变浏览器的默认按钮。透明图标、SHA256 校验和及开源构建不等于代码签名，也不能保证消除警告。正式改善发布者身份需要受信任的 Authenticode 代码签名证书及时间戳，签名后仍可能需要建立下载信誉。不要为此关闭 SmartScreen 或杀毒保护。更新入口打开 Windows 发布列表供手动下载，不自动安装。

## 构建和验证

需要 JDK 21、Python 3。依赖 JAR 随仓库提供并校验 SHA256。Windows 单文件打包使用系统 .NET Framework C# 编译器及7-Zip，无需 WiX。内嵌的官方7zr精简解压程序校验SHA256，归属和许可见 vendor/NOTICE.md。

```sh
python desktop/build.py
# Windows 生成单文件 EXE：
python desktop/build.py --package
```

构建检查真实页面样本解析、分类与提取码关联、缺码标注、筛选和成人过滤；Windows 上还运行最终单文件 EXE，验证临时解压、内置运行环境启动、15条分页、交互筛选、连续点击启停、取消确认和关闭时清理状态。来源实时可用性和用户电脑上的应用关联仍取决于当地网络及安装的软件。

## Windows 发行者签名

当前自动发布没有可用的受信任代码签名身份，故仍可能出现“Windows 已保护你的电脑 / 发布者未知”。固定文件名、ZIP、填写文件属性和自签证书都不能建立受信任发行者；本次命名改动不表示已解决 SmartScreen。

已提供在签名持有人的 Windows 机器上使用现有证书的构建入口（证书位于当前用户个人证书存储，亦可由硬件密钥提供）：

```powershell
python desktop/build.py --package --sign-thumbprint YOUR_40_HEX_CERTIFICATE_THUMBPRINT
```

流程为编译EXE → Authenticode SHA256签名与RFC3161时间戳 → 验证受信任证书链 → 启动测试 → ZIP → 生成最终校验和。需要 Windows SDK 的 SignTool。证书、私钥及密码不应放入仓库或聊天。签名或证书链验证失败时停止打包；有正式签名后 SmartScreen 仍可能需要建立信誉。

如果使用 Azure Artifact Signing 或 SignPath，需要先由项目所有者申请、完成身份／项目审核并授权签名账号，才能接入其云签名步骤；不能用公共匿名签名服务器替代受信任身份。
