# 寻源 Windows 0.1.0

适用于 Windows 10/11 x64，无需安装 Java。提供 EXE 安装程序和便携 ZIP；便携版必须先完整解压，再运行其中的 `Xunyuan.exe`，不能单独移动启动器。

## 功能

- 输入关键词，聚合所勾选来源的网盘与磁力结果，支持类型筛选。
- 每屏最多15条；翻页保留关键词，当前结果显示完后可继续加载来源下一批。
- 复制分享链接／提取码，保存和移除本机收藏。
- 扩展搜索每次启动默认关闭，开启前确认已满18岁。扩展来源须在搜索来源中另行勾选。
- 默认来源与安卓相同，共用 Source、Result、SearchEngine 源码；失效备用来源默认不勾选。

网盘链接交给 Windows 默认浏览器或已注册的链接关联处理程序；磁链交给已注册 magnet 协议的下载工具。不能保证网盘客户端直接接管 HTTPS 地址，打开失败时自动复制地址。提取码存在时，打开资源前复制提取码。

请求从电脑直连第三方站点，无自建搜索服务器。需要验证码、网络受限、来源失效时可在「关于」查看每个来源的错误。关键词过滤不能保证识别所有未标注内容。

收藏保存在 `%LOCALAPPDATA%\Xunyuan\favorites.json`，不自动上传。开关和来源选择仅保存在当前运行会话。

安装包未配置 Windows 代码签名证书，系统可能显示未知发布者。版本与更新入口打开当前 Windows 发布页供手动下载，此版本不自动下载或安装更新。

## 构建和验证

JDK 21、Python 3，依赖 JAR 已随仓库提供并校验 SHA256。Windows 打包另需 WiX 3.x，并将其 bin 目录加入 PATH。

```sh
python desktop/build.py
# Windows 创建安装程序和便携版：
python desktop/build.py --package
```

`--self-test` 在最终打包运行时检查六个默认来源的真实页面样本解析、结果去重、链接校验及成人过滤；`--smoke-test` 用离线数据启动桌面并截图。它们不等同于所有来源的实时网络可用性或用户电脑上的协议关联验证。
